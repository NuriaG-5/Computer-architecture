# MIPS Pipelined Processor with Memory-Mapped PWM Control
A 5-stage pipelined MIPS processor that uses Memory-Mapped I/O to control a PWM signal from external switch inputs.

## Project Overview

This project implements a 5-stage pipelined MIPS processor with Memory-Mapped I/O (MMIO) support. The processor reads the value of external switches and uses that value to control the duty cycle of a PWM (Pulse Width Modulation) signal generated by dedicated hardware.

The design includes hazard detection, forwarding logic, branch handling, and MMIO peripherals integrated into the data memory subsystem.

## Features

- 5-stage MIPS pipeline:
  - Instruction Fetch (IF)
  - Instruction Decode (ID)
  - Execute (EX)
  - Memory Access (MEM)
  - Write Back (WB)

- Data forwarding
- Hazard detection unit
- Load-use hazard stalling
- Branch and jump support
- Memory-Mapped I/O (MMIO)
- PWM controller
- Switch input interface

---

## MMIO Address Map

| Address | Device | Direction | Notes |
|----------|----------|----------|----------|
| 0x90 | Switches | Read Only | Returns the current switch value |
| 0x98 | PWM Duty Cycle Register | Write Only | Sets PWM duty cycle (0–255) |
| 0x9C | PWM Enable Register | Write Only | Enables or disables PWM output |
---

## System Operation

The processor performs the following tasks:

1. Enable the PWM module.
2. Read the current value of the switches.
3. Write the switch value to the PWM duty-cycle register.
4. Repeat continuously.

As a result, the PWM duty cycle changes according to the switch settings.

---

## MIPS Program

```assembly
addi $t0, $zero, 1
sw   $t0, 156($zero)

loop:
lw   $t1, 144($zero)
sw   $t1, 152($zero)
j    loop
```

## Signals of Interest

The following signals are useful for verifying system operation:

- `switches[7:0]`
- `pwm_duty[7:0]`
- `counter[7:0]`
- `pwm_out`

These signals demonstrate the complete data flow:

```
switches
    ↓
MMIO Read (0x90)
    ↓
PWM Duty Register (0x98)
    ↓
PWM Controller
    ↓
pwm_out
```

## Expected Results

Example operation:

| Switch Value | PWM Duty Cycle |
|--------------|---------------|
| 0x40 | 25% |
| 0x80 | 50% |
| 0xC0 | 75% |
| 0xFF | ~100% |

When the switch value changes, the PWM duty cycle updates accordingly.
